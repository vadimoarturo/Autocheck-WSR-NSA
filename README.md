# WorldSkills Infrastructure Automation

**Infrastructure automation for WorldSkills Network & System Administration lab environments (2020).**

A collection of PowerShell and Python scripts developed to help prepare, inspect, and validate competition lab environments across VMware ESXi, Linux, Windows and Cisco network devices.

## What this project demonstrates

- VMware-based lab infrastructure orchestration and remote access
- Automated infrastructure verification across operating systems
- PowerShell and Python scripts for repeatable, multi-host operational tasks
- Networking and systems administration in time-constrained environments

## Structure

- `Demo2020/Linux/` — PowerShell routines for Linux virtual machines
- `Demo2020/Windows/` — PowerShell routines for Windows virtual machines
- `Demo2020/Cisco/` — Python routines for Cisco equipment
- Example result files — representative test output

## Historical lab project

This is an **archived competition-oriented code sample** rather than a supported production automation package. It references historical lab accounts, addresses, systems and device-specific assumptions. Any credentials in historical scripts or test output are **lab examples, not instructions for production use**. Do not reuse them on accessible infrastructure.

Before using these scripts in a new environment, review device commands, supply new credentials securely, adapt the topology and validate their effects in an isolated lab.
